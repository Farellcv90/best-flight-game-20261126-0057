Langit Nusantara: Island Courier — a complete original 3D flight game over a golden-hour Indonesian archipelago. Take off from the island runway, fly through 5 glowing delivery rings in order, refuel at the amber fuel ring, then land back on the runway. Arcade flight model with throttle, pitch/roll, stall, wind gusts, fuel burn and damage; chase and cockpit cameras; a lit HUD with altitude, speed, heading, throttle, fuel and an artificial horizon; and WebAudio-synthesised engine, wind and chime sounds. Keyboard + mouse, desktop browser, static files, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and fly.
